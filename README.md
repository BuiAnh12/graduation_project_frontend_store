# The Application – Food Application for Store

## Quick preview

This is the management application for the store site. It provides essential tools for handling daily operations, managing staff, and improving service quality.

## Features

- Authentication

Secure login, role-based access control, and account protection.

- Order Management

Create, update, track, and manage customer orders throughout the entire process.

- Menu Management

Add, edit, remove, and organize menu items efficiently.

- Rating & Review Management

View and handle customer ratings to maintain and improve service quality.

- Staff Management

Manage staff information, roles, and access permissions.

- Rating & Review Management

View and handle customer ratings to maintain and improve service quality.

- Analytics & Reports

View key statistics such as total orders, revenue insights, customer activity, and more.

## Technology Stack

This application is built using modern web technologies to ensure high performance, scalability, and maintainability.

- Next.js – Framework for server-side rendering, routing, and optimized performance.

- React.js – Core library for building dynamic and interactive UI components.

- Additional Libraries & Tools – Various supporting libraries for state management, UI components, API handling, and utilities.

# Getting Started
This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3001](http://localhost:3001) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
